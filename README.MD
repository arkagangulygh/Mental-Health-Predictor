# Mental Health Signal

A machine learning web application that predicts a student's mental health score based on lifestyle, academic, digital usage, and stress-related factors.

### 🚀 Live Demo

**Frontend:** https://mental-health-predictor-ten.vercel.app/

**Backend API:** https://mental-health-predictor-tzdo.onrender.com/

## Features

* ML-based mental health score prediction
* FastAPI REST API
* Interactive and responsive frontend
* Input validation with Pydantic
* Dynamic score visualization
* Deployed using Vercel and Render

## Tech Stack

**Machine Learning:** Python, Pandas, Scikit-learn, Joblib
**Backend:** FastAPI, Pydantic, Uvicorn
**Frontend:** HTML, CSS, JavaScript
**Deployment:** Vercel, Render
**Version Control:** Git & GitHub

## How It Works

```text
User Input → Frontend → FastAPI → ML Model → Prediction → Result
```

The trained model processes lifestyle and behavioral inputs and returns a predicted mental health score.

## Disclaimer

This project is developed for educational purposes. The prediction is not a medical diagnosis or a substitute for professional mental health advice.
